# Дурак: счётчик карт

Приложение для Mac и телефона. Отмечай карты по ходу партии: что ушло в бито, что забрал соперник, сколько козырей осталось.

## Mac

Готовые сборки:
- `Durak-mac-arm64.zip` — для Mac на Apple M1/M2/M3/M4 (почти все Mac с 2021 года);
- `Durak-mac-x64.zip` — для старых Mac на Intel.

Какой у тебя Mac: меню  → «Об этом Mac». Если написано «Chip Apple M…», бери arm64.

1. Распакуй zip и перетащи `Дурак.app` в папку «Программы».
2. Приложение не подписано Apple, поэтому один раз открой «Терминал» и выполни:
   ```
   xattr -cr /Applications/Дурак.app
   codesign --force --deep -s - /Applications/Дурак.app
   ```
3. Запускай как обычное приложение. Если macOS всё равно ругается: «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть».

Собрать самому (нужен Node.js): `npm install`, затем `npm run mac-arm` или `npm run mac-intel`. Готовое приложение появится в `dist/`. Запустить без сборки: `npm start`.

## Телефон (iPhone и Android)

Папка `www/` — это веб-приложение (PWA): с иконкой, на весь экран, работает без интернета.

1. Выложи папку `www/` на любой хостинг с https. Проще всего перетащить её на https://app.netlify.com/drop, либо задеплоить на Vercel или GitHub Pages.
2. Открой полученную ссылку на телефоне:
   - iPhone (Safari): «Поделиться» → «На экран "Домой"»;
   - Android (Chrome): меню ⋮ → «Установить приложение» или «Добавить на главный экран».

Такая же установка работает на Mac: Safari → «Файл» → «Добавить в Dock».
